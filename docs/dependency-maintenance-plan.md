Статус: запланировано; workflow в текущем этапе не изменяются.

Шесть notices из присланного пользователем запуска сообщают об одном изменении
окружения `ubuntu-latest`, а не о шести независимых ошибках сборки:

| `notify_telegram_after_deploy / get_last_commit` | Вызов `.github/workflows/github-telegram.yml` |

Источник: [actions/runner-images#14748](https://github.com/actions/runner-images/issues/14748).
На 2026-10-27 в объявлении указан постепенный переход с Ubuntu 24.04
на Ubuntu 26.04 с 2026-10-19 по 2026-11-19. URL запуска Actions пользователь
не передал; фактический образ runner конкретного запуска не проверен.

- [ ] Проверить Setup job / Runner Image в затронутом запуске Actions.
- [ ] Инвентаризировать активные `runs-on: ubuntu-latest` во всех workflow
  шаблона, включая `action-pages.yml`, `github-telegram.yml`, `update_cars.yml`
  и `linkinator.yml`.
- [ ] Проверить Node.js 24, pnpm, нативные зависимости, Python/Pillow/lxml,
  системные утилиты и подготовку артефактов на Ubuntu 26.04. Проверки должны
  обходиться без реального деплоя и отправки уведомлений.
- [ ] По результатам выбрать явный `ubuntu-26.04` либо временно закрепить
  `ubuntu-24.04`, если обнаружатся проблемы совместимости.
- [ ] Исправление общих workflow внести в `astro-components`, затем провести
  через merge-цепочку `astro-brand-*` → `astro-dealer-*` и `astro-main-*`
  с проверками каждого уровня. Массовую раскатку выполнять отдельным этапом.

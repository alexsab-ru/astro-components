# CollapsibleText

Общий механизм ограничения содержимого по высоте (`mode="height"`) или числу
строк (`mode="lines"`). Принимает произвольное содержимое через default slot.
Не загружает MDX и не содержит оформления SEO, rich content или подвала:
их прежние props, классы, подписи и правила прокрутки остаются в обёртках.

| Обёртка | Свёрнутый вид | Подписи | Прокрутка после переключения |
| --- | --- | --- | --- |
| `SeoText` | До 230 px, градиент, стрелка | читать полностью / скрыть | Только при сворачивании к своему тексту |
| `RichContentMore` | До 90 px, от 64 rem — 55 px, градиент | Подробнее / Свернуть | Нет |
| `DisclaimerCollapse` | До трёх строк | Показать все + / Скрыть - | В обоих случаях к своему корню с вычетом высоты `#site_nav` |

```astro
<CollapsibleText mode="lines" collapsedLines={4} expandLabel="Читать дальше">
    <p>Произвольный Astro/MDX-контент.</p>
</CollapsibleText>
```

`collapsedHeight` — CSS-длина или выражение (`230px` по умолчанию),
`collapsedLines` — число строк (`3`). Адаптивную высоту обёртка может передать
через CSS-переменную. `class`, `contentClass`, `buttonClass`, `actionsClass`
оформляют части компонента; `collapsedContentClass` применяется только к
свёрнутому тексту. Иконка кнопки — named slot `toggle-icon`.
Затухание включается через `fade`: прозрачная CSS-маска скрывает последние
100 px содержимого, не рисуя цветную подложку. Оно одинаково работает на белом,
сером, тёмном фоне и изображении; подбирать цвет фона не требуется.
Прежняя `--collapse-fade-color` больше не используется.
Прокрутка задаётся `scroll="none|collapse|toggle"`, `scrollTarget="content|root"`
и необязательным `scrollOffsetSelector` для вычета высоты внешнего элемента.

Если текст помещается целиком, кнопка, её отступы и градиент скрыты, высота
естественная. Переполнение измеряется в свёрнутом состоянии, даже если текст
сейчас раскрыт. ResizeObserver, MutationObserver, события загрузки изображений
и шрифтов обновляют результат. В скрытой панели измерение откладывается до
появления. Выбор раскрытия сохраняется при изменении размеров.
Как и раньше, у RichContentMore SEO-типографика применяется только в свёрнутом состоянии.

HTML содержит весь текст. Без JS он полностью доступен, кнопка скрыта.
Модуль компонента включает ограничение высоты и кнопку с `aria-expanded` и
`aria-controls`; уникальный ID используется только для доступной связи.
Каждый экземпляр сам хранит состояние и ссылки на свои элементы, включая вложенные.
Нативная кнопка поддерживает Tab, Enter и Space. Reduced motion отключает плавную прокрутку.

Старый SEO-обработчик из `app.js` удалён. Alpine больше не нужен этим трём компонентам;
`js/alpine/footer.js` остаётся для отдельного старого `FooterV1`.

Проверка: `node --test src/ui/collapsible-text/collapsible-text.test.mjs`.

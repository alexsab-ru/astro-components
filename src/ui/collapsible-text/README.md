# CollapsibleText

Общий механизм для `SeoText`, `RichContentMore` и `DisclaimerCollapse`.
Их прежние props и выбор HTML/MDX сохраняются; данные сайта не меняются.

| variant | Свёрнутый вид | Подписи | Прокрутка после переключения |
| --- | --- | --- | --- |
| `seo` (по умолчанию) | 230 px, градиент, стрелка | читать полностью / скрыть | Только при сворачивании к своему тексту |
| `rich` | 90 px, от 64 rem — 55 px, градиент | Подробнее / Свернуть | Нет |
| `disclaimer` | Три строки | Показать все + / Скрыть - | В обоих случаях к своему корню с вычетом высоты `#site_nav` |

```astro
<CollapsibleText variant="rich" expandLabel="Читать дальше" collapseLabel="Свернуть">
    <p>Произвольный Astro/MDX-контент.</p>
</CollapsibleText>
```

`class`, `contentClass`, `buttonClass` дополняют оформление соответствующих частей.
`--collapse-fade-color` задаёт цвет градиента (по умолчанию белый, как у старого SEO).
Короткий текст сохраняет прежнюю фиксированную высоту и переключатель;
автоматического скрытия кнопки при отсутствии переполнения нет.
Как и раньше, у RichContentMore SEO-типографика применяется только в свёрнутом состоянии.

HTML содержит весь текст. Без JS он полностью доступен, кнопка скрыта.
Модуль компонента включает ограничение высоты и кнопку с `aria-expanded` и
`aria-controls`; уникальный ID используется только для доступной связи.
Каждый экземпляр сам хранит состояние и ссылки на свои элементы, включая вложенные.
Нативная кнопка поддерживает Tab, Enter и Space. Reduced motion отключает плавную прокрутку.

Старый SEO-обработчик из `app.js` удалён. Alpine больше не нужен этим трём компонентам;
`js/alpine/footer.js` остаётся для отдельного старого `FooterV1`.

Проверка: `node --test src/ui/collapsible-text/collapsible-text.test.mjs`.

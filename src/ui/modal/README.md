# Общая оболочка окна

`Modal.astro` отвечает за подложку, панель, крестик, ARIA и слот содержимого.
`modal-controller.js` один раз подключает открытие, закрытие, Escape, блокировку
прокрутки и focus-trap. Библиотека удерживает Tab/Shift+Tab в окне; после
закрытия фокус возвращается к доступному триггеру.

```astro
import Modal from '@/ui/modal/Modal.astro';

<a class="popup-link btn" href="#details-modal">Подробнее</a>
<Modal id="details-modal" title="Подробности" description="Необязательная подпись">
  <p>Произвольное содержимое.</p>
  <button type="button" class="btn" data-close>Готово</button>
</Modal>
```

У каждого окна собственный уникальный `id`. `size="wide"` меняет max-w-xl на
max-w-2xl, `backdrop="soft"` — непрозрачность подложки 70% на 50%.
`panelClass` и `closeColor` сохраняют настройку оформления. Без title можно
передать `aria-label` либо `aria-labelledby` своего заголовка внутри слота.
Для стандартного title/description созданы локальные ID относительно id окна.

Короткая панель центрируется по вертикали и горизонтали. Высокая начинается
с безопасного отступа и прокручивается целиком внутри подложки: верх окна
не уходит за пределы доступной области, а фокус может прокрутить к нижним полям.
Высота подложки использует 100dvh с прежним h-screen как fallback; отступы
учитывают safe-area телефона. Прокрутка страницы под окном остаётся заблокированной.

На страницах через Layout, PageLayout, CarPageLayout, CarsListLayout и LegalPage
размещайте дополнительные окна в именованном слоте `modals`. Он передаётся в
общую композицию в конце body, отдельно от контейнеров основного контента.

```astro
<PageLayout title="Страница">
  <a class="popup-link btn" href="#details-modal">Подробнее</a>
  <Modal slot="modals" id="details-modal" title="Подробности">
    <p>Содержимое нового окна.</p>
  </Modal>
</PageLayout>
```

Для программного вызова экспортируются `openModal(element, trigger?)` и
`closeModal(element)`. Добавление/удаление `hidden` также поддерживается:
SDK продолжает открывать свои окна прежним способом. События на самом окне:
`modal:beforeopen`, `modal:open`, `modal:beforeclose`, `modal:close`.
В detail открытия доступны trigger и reason; адаптер данных не дублирует
механику окна. Подложка и `[data-close]` закрывают только выбранное окно;
закрытие верхнего подтверждения не разблокирует фон оставшегося окна.
Слои упорядочиваются по открытию: служебное подтверждение SDK остаётся поверх
нового окна из слота независимо от их порядка в HTML.

Оболочка не содержит отправку форм, аналитику или конфигурацию дилера.
Для формы заявки используется отдельный адаптер из site-shell/modals.

Проверки: `node --test src/ui/modal/modal-controller.test.mjs`.

# Tabs

Переключатель произвольных панелей. Состав панели задаётся именованным слотом,
совпадающим с `items[].id`; данные автомобилей и условия акций остаются снаружи.

```astro
<Tabs
	label="Варианты предложения"
	items={[
		{ id: 'description', label: 'Описание', image: { src: '/example.webp', alt: 'Пример' } },
		{ id: 'details', label: 'Подробности' },
	]}
	scrollOnChange
>
	<div slot="description">Любая разметка или компоненты</div>
	<div slot="details">Другая панель без общей картинки</div>
</Tabs>
```

- `initial` — ID начальной вкладки; по умолчанию первая.
- `variant` — `filled` (по умолчанию) или `outline`.
- `listClass`, `buttonClass`, `contentClass`, `mediaClass`, `imageClass`, `class` —
  оформление контейнеров. По умолчанию вкладки идут одной строкой с горизонтальной
  прокруткой; страницы WEY и Jetour сохраняют существующую сетку.
- `image` необязательно: выбранная вкладка меняет общую картинку и её `alt`;
  панель также может содержать собственные картинки, видео и вложенные компоненты.
- `scrollOnChange` прокручивает к локальному контейнеру содержимого при клике.
  Отступ задаёт CSS-переменная `--tabs-scroll-offset`. Стрелки, Home и End меняют
  вкладку и фокус без прокрутки к панели; учитывается reduced motion.
- Tab входит в группу на активную кнопку, затем переходит к панели. Стрелки,
  Home и End перемещают фокус внутри группы и сразу переключают содержимое.
- Навигация резервирует 6 px для внешней рамки фокуса, в том числе при прокрутке.
  Общие `--color-focus-ring` и `--color-focus-ring-gap` задают тёмную рамку
  и светлый зазор для всех интерактивных элементов сайта.

## Цвета бренда

Значения по умолчанию объявлены в `src/scss/base/theme.css`; переопределять их
нужно в `src/scss/brands/<brand>.css` через `@theme`. В Tabs нет фиксированных
цветов. Выбранная вкладка наследует фон и текст стандартной кнопки бренда.

| Состояние | Фон | Текст | Граница |
| --- | --- | --- | --- |
| Обычная вкладка | `--color-tabs-bg` | `--color-tabs-text` | `--color-tabs-border` |
| Наведение | `--color-tabs-bg-hover` | `--color-tabs-text-hover` | `--color-tabs-border-hover` |
| Выбранная | `--color-tabs-bg-active` | `--color-tabs-text-active` | `--color-tabs-border-active` |
| Контурная вкладка | `--color-tabs-outline-bg` | `--color-tabs-outline-text` | `--color-tabs-outline-border` |
| Наведение на контурную | `--color-tabs-outline-bg-hover` | `--color-tabs-outline-text-hover` | `--color-tabs-outline-border-hover` |

Например, отдельное оформление выбранной вкладки без изменения остальных кнопок:

```css
@theme {
	--color-tabs-bg-active: var(--color-accent-500);
	--color-tabs-text-active: var(--color-white);
	--color-tabs-border-active: var(--color-accent-400);
}
```

Те же переменные можно задать на отдельном контейнере через обычный CSS.
Для светлого активного фона задайте тёмный текст с контрастом не ниже 4.5:1.

Состояние каждого экземпляра независимо; глобальных селекторов, URL или хранилища
нет. Сгенерированные уникальные ID связывают только ARIA-атрибуты. Без JavaScript
навигация скрыта, все панели доступны последовательно. Компонент подключает свой
скрипт один раз и не зависит от Alpine.

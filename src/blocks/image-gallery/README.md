# Галереи изображений

`ImageGallery` использует одну подготовку раскладки и общий `GalleryImage`
для ссылки, изображения, alt и подписей GLightbox. Компоненты не создают
собственных клиентских обработчиков: используется существующий GLightbox сайта.
Без JS ссылка ведёт прямо к изображению.
Навигация и закрытие остаются у GLightbox: стрелки клавиатуры и Escape;
на узком экране экранные стрелки скрыты, доступно перетаскивание изображения.

```astro
<ImageGallery images={images} layout="simple" title="Демонстрационные фотографии" />
```

Входное изображение: `{ url, title?, description? }`.
`layout="mosaic"` (по умолчанию) сохраняет прежние шаблоны для 1–6 изображений,
блоки по шесть и отдельное широкое седьмое. `layout="simple"` — две колонки,
единственное или нечётное последнее изображение естественной высоты.
Пустой массив ничего не выводит. `title` задаёт только запасной alt,
а не видимый заголовок галереи. Пустой title самого изображения остаётся пустым.

| Совместимая обёртка | Параметры общего механизма |
| --- | --- |
| `ImageGalleryGrid` | mosaic; descriptionMode=text; прежние images/gallery |
| `ImageGallerySimpleGrid` | simple; descriptionMode=html; прежние images/gallery/title |
| `ImageGallerySections` | Прежние заголовки, фильтрация пустых секций, variant и CTA между секциями |

`descriptionMode="text"` по прежнему правилу удаляет HTML-теги из описания;
`html` сохраняет разметку описания, как раньше в SimpleGrid.
Режим подписи задаётся отдельно от раскладки. `GalleryImage` принимает также
`linkClass` и `imageClass`; общий механизм не меняет размеры исходных файлов.

Без `gallery` каждый экземпляр получает собственную группу. С одинаковым
явно заданным `gallery` можно намеренно объединить несколько галерей.
У каждого `ImageGallerySections` свой префикс, поэтому одинаковые section.id
в разных экземплярах не смешиваются в лайтбоксе. Публичных DOM ID нет.

Проверка подготовки раскладок, подписей и групп:
`node --test src/blocks/image-gallery/gallery.test.mjs`.

## Фотолента ImageCarousel

Самостоятельный слайдер семейства галерей использует тот же GalleryImage.
Принимает обычный массив images (url, alt, title, description), без модели.
По умолчанию fullBleed=true — до краёв экрана; false оставляет контейнерную ширину.
У каждого экземпляра своя группа просмотра и локальный Swiper; одинаковый
явный gallery намеренно объединяет фотографии. GLightbox остаётся общим.
Картинки загружаются лениво, после загрузки Swiper обновляет размеры слайдов.

```astro
<ImageCarousel images={[{url:'/photo.webp',alt:'Описание'}]} fullBleed />
```

GalleryImage дополнительно принимает необязательные alt и loading; старые
вызовы Grid/SimpleGrid сохраняют прежние значения. ModelPhotos — только адаптер
model.photos к этой общей фотоленте.

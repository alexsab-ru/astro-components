# Отзывы

`ReviewCard` — общий статический компонент отзыва. Принимает `item` с `name`,
`text`, `date` (`string | Date`), `variant="quote|bubble"` и необязательный `class`.
Текст и имя выводятся как текст, без `set:html`. Дата остаётся в переданном виде;
новое форматирование и часовой пояс этим извлечением не вводятся.

| Компонент | Назначение |
| --- | --- |
| `ReviewCard` с `quote` (по умолчанию) | Белая карточка-цитата: автор сверху, текст без ограничения, дата снизу |
| `ReviewCard` с `bubble` | Текст в белой плашке с прокруткой до 200 px, иконка и автор с датой снаружи снизу |
| `Review` | Совместимая обёртка `quote`, прежний вызов `item` сохранён |
| `ReviewsItem` | Совместимая обёртка `bubble` внутри `.swiper-slide` |
| `Reviews` | Секция, фильтрация `show`, навигация, пагинация и настройки Swiper |

```astro
<ReviewCard item={{ name: 'Демонстрационный автор', text: 'Текст отзыва.', date: '17 ноября 2026' }} variant="bubble" />
```

`ReviewCard`, `Review` и `ReviewsItem` не фильтруют `show`: прямой вызов отображает
переданный отзыв, как раньше. Только `Reviews` выбирает видимые элементы.
Карточка не содержит ID, Swiper, клиентского JS, загрузки данных и навигации.
Существующие классы, размеры, тень, скругления и прокрутка сохранены.

Логика `Reviews` намеренно остаётся прежней. Её фиксированные `id="reviews"`
и общие селекторы навигации пока предполагают один слайдер отзывов на странице.
Несколько самостоятельных карточек не имеют этого ограничения.

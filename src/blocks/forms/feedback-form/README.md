# FeedbackForm

`imageUrl` сохраняет прежний вариант с одной картинкой. Для адаптивной мозаики
передайте `images`: массив URL или объектов `{ imageUrl, alt }`. Непустой массив
имеет приоритет над `imageUrl`; пустой массив использует `imageUrl`, если он задан.
Без фотографий выводится обычная форма.

```astro
<FeedbackForm
    title="Обменяй свой авто на GAC с выгодой"
    subtitle="Оставьте данные, и мы перезвоним"
    dataFormName="Оценить авто. Trade-in GAC"
    labelBtn="Оценить авто"
    images={[
        { imageUrl: '/photos/showroom.webp', alt: 'Автомобили в шоуруме' },
        '/photos/car.webp',
        '/photos/reception.webp',
        '/photos/awards.webp',
    ]}
/>
```

Для 1–4 фотографий предусмотрены отдельные раскладки. Четыре фотографии образуют
два ряда: второй и четвёртый снимки занимают узкие ячейки, первый и третий —
широкие. Для 5 и более используется сетка из двух колонок; последний нечётный
кадр занимает весь ряд. Изображения заполняют ячейки с обрезкой по центру.
На экранах уже 1024 px мозаика располагается над формой.

Для содержательных снимков передавайте `alt`; URL без подписи считается
декоративным изображением (`alt=""`).

Параметры `images` и `labelBtn` также доступны в блоке `feedback-form` Page Builder
и в `feedbackForm` RichContent. Поля и обработка отправки остаются общими
с `FeedbackFormFields.astro`.
